# Cairn Documentation

Cairn documentation is organized for two primary audiences:

- **Facilities**: operators, owners, managers, instructors, and front desk teams using Cairn day to day.
- **Developers**: engineers extending Cairn, maintaining mock/demo infrastructure, and preparing the platform for real integrations.
