# Alerts & Tasks

## Overview

Cairn includes an operations alert and task center for surfacing issues across customers, memberships, waivers, programs, inventory, finance, and staff.

## Common Workflows
- review critical alerts
- resolve or archive an alert
- create follow-up tasks
- open a related customer, waiver, or membership record

## Step-by-Step: Resolve an Alert
1. Open **Alerts**.
2. Filter by severity, type, or status.
3. Open the alert card.
4. Review the linked record.
5. Resolve or archive the alert, or create a task for follow-up.

## Tips
- Treat alerts as operational triage, not permanent notes.
- Use tasks when work must be assigned or deferred.
- Dashboard alert widgets should be used as quick entry points.
