# Alerts

## Overview
Alerts and tasks surface operational problems without forcing staff to search through every module manually.

## What You Can Do
- review open alerts by severity and type
- resolve or archive alerts
- create follow-up tasks
- review dashboard counts for alerts and tasks due today
- use alerts within customer, membership, and waiver contexts

## Alert Types
- customer alerts
- membership alerts
- waiver alerts
- program alerts
- inventory alerts
- financial alerts
- staff alerts

## Common Workflows
### Manage alerts
1. Open Operations Alerts.
2. Filter by severity, type, or status.
3. Open the related record.
4. Resolve or archive the alert.
5. Create a task if follow-up is still needed.

### Review customer alerts
1. Open the customer profile.
2. Review open alerts and history.
3. Resolve the alert when the issue is cleared.

### Use dashboard alert widgets
1. Open the dashboard.
2. Select `Open Alerts`, `Critical Alerts`, or `Tasks Due Today`.
3. Continue into Alerts with the relevant focus.

## Tips
- Alerts should represent actionable issues, not general notes.
- Use tasks when the issue requires human follow-up instead of immediate resolution.
- Review critical alerts first during opening shifts.
