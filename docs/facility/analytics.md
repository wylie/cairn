# Analytics

## Overview

Reports & Analytics consolidates operational dashboards, executive summaries, filtered reports, and drill-down views across revenue, attendance, memberships, programs, waivers, households, rentals, communications, and staff activity.

## Common Workflows
- review daily operational health
- open drill-downs from dashboard widgets
- compare locations
- save report filters
- export report output

## Step-by-Step: Run a Report
1. Open **Reports & Analytics**.
2. Choose a category.
3. Set a date range and filters.
4. Review charts, summary cards, and drill-down tables.
5. Export if needed.

## Tips
- Dashboard metrics are intended to be actionable entry points, not static numbers.
- Saved filters help teams reuse common operational views.
- Some exports are placeholder implementations today; verify the downstream use case before promising polished external reporting.
