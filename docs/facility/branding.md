# Branding

## Overview

Cairn supports organization-specific branding across the facility landing page, customer portal, digital membership cards, waivers, and staff-facing references.

## Configurable Items
In **Settings → Branding** you can manage:
- primary brand color
- secondary brand color
- facility nickname
- logo
- dark mode logo
- favicon
- preview states

Facility profile settings also supply:
- organization name
- description
- email
- phone
- website
- address

## Common Workflows
- upload a new logo
- update brand colors for a rebrand
- confirm branding on the public landing page
- confirm cards and waivers inherit the right organization identity

## Step-by-Step: Update Branding
1. Open **Settings**.
2. Select **Branding**.
3. Update colors, nickname, and image assets.
4. Save branding.
5. Review:
   - `/f/:orgSlug`
   - `/p/:orgSlug/dashboard`
   - membership cards
   - waiver views

## Tips
- Provide both a primary logo and dark mode logo where possible.
- If no logo is uploaded, Cairn falls back to the organization name instead of a broken image.
- Use the same brand colors on public and customer-facing workflows to build trust.
