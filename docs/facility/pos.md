# POS

## Overview

Cairn POS handles access sales, products, memberships, passes, household-aware purchases, receipts, transaction history, and post-sale check-in flows.

## Common Workflows
- find a customer and sell access
- add retail items to cart
- apply a discount
- use split payment fields
- view transaction history and receipts

## Step-by-Step: Complete a Sale
1. Open **POS**.
2. Select a customer.
3. Add access products, memberships, or retail items.
4. Review pricing, taxes, and discounts.
5. Choose payment method.
6. Complete checkout.
7. If access was sold, complete any post-sale check-in or waiver actions.

## Tips
- Membership and access rules affect pricing and eligibility.
- Receipt history is useful for both staff support and customer self-service.
- Household-aware purchases should distinguish purchaser vs beneficiary when relevant.
