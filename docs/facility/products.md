# Products

## Overview

Products drive access, POS catalog items, memberships, passes, rentals, and other purchasable records inside Cairn.

## Common Workflows
- create a product
- edit pricing and cost
- manage tags and categories
- upload a product image
- configure age or access rules
- manage inventory and quick buttons

## Step-by-Step: Create a Product
1. Open **Products**.
2. Create a new product.
3. Complete:
   - overview
   - classification
   - access rules
   - eligibility / age rules
   - inventory
   - online visibility
   - appearance
4. Save and verify the product appears in POS or public catalog where appropriate.

## Tips
- Use categories and tags consistently; they shape search and reporting.
- Product images should be present for retail and public-facing experiences when possible.
- Access-related products should be reviewed alongside membership, waiver, and check-in workflows.
