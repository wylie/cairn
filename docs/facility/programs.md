# Programs

## Overview

Programs define the customer-facing offerings that later become sessions, rosters, attendance records, registrations, waitlists, and reporting data.

## Common Workflows
- create a new program
- configure program defaults
- create sessions from a program
- review program health and capacity issues
- move into registration operations

## Step-by-Step: Create a Program
1. Open **Programs**.
2. Create a new program.
3. Define title, description, category, age range, pricing, and defaults.
4. Create one or more sessions.
5. Review the public program page and registration panel.

## Tips
- Program defaults make session creation faster when schedules repeat.
- Required waivers and membership rules should be reviewed alongside registration flow expectations.
- For daily operations, Programs and Registrations are complementary workspaces: setup happens in Programs, fulfillment happens in Registrations.
