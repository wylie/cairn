# Registrations

## Overview

The Registrations workspace is the operational center for rosters, attendance, waitlists, promotions, and customer enrollment activity.

## Common Workflows
- register a customer into a session
- review roster status
- manage waitlist promotions
- mark attended or absent
- review registration history and receipt links

## Step-by-Step: Manage a Session Roster
1. Open **Registrations**.
2. Search or select a session.
3. Review roster members and waitlist entries.
4. Use actions such as:
   - Check In
   - Mark Attended
   - Mark Absent
   - Remove
   - Move To Another Session
5. Review timeline and audit history for the registration.

## Tips
- Registration detail should answer status, participant, receipt, and waiver state in one place.
- Waitlist promotion should be used intentionally when capacity changes.
- Public registration and staff registration should lead to the same underlying registration record patterns.
