# Registrations

## Overview
Registrations cover program enrollment, roster management, waitlists, attendance, receipts, waiver checks, and household participant selection.

## What You Can Do
- create and manage program registrations
- review session rosters and attendance
- enroll customers from staff workflows
- review waitlists and capacity issues
- connect registrations to households, waivers, memberships, and receipts

## Common Workflows
### Create a registration
1. Open Registrations.
2. Select the program or session.
3. Search for the customer.
4. Review eligibility, membership requirements, and waiver status.
5. Complete enrollment.

### Manage attendance
1. Open the selected session.
2. Review the roster.
3. Mark attendance.
4. Review participant details or waiver status as needed.

### Handle a waitlist
1. Open the session detail.
2. Review waitlisted customers.
3. Promote eligible customers when space opens.
4. Confirm communication and receipt updates.

### Register from the customer-facing flow
1. Start from the public program catalog.
2. Select a participant from the authorized household.
3. Complete eligibility, waiver, cart, checkout, and confirmation steps.

## Tips
- Use the registrations workspace for operational overrides and roster decisions.
- Use the customer portal for self-service review of upcoming and past registrations.
- Keep prerequisites and waiver requirements current to reduce manual intervention.
