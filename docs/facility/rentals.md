# Rentals

## Overview
Rentals manage rentable resources, reservations, maintenance blocks, conflicts, and customer-facing reservation flows.

## What You Can Do
- create and manage rentable resources
- reserve inventory or spaces for customers
- block resources for maintenance
- check resources in and out
- review utilization and conflict alerts

## Common Workflows
### Create a rental resource
1. Open Rentals.
2. Add the resource.
3. Set location, availability, and pricing details.
4. Save.

### Create a reservation
1. Open Rentals.
2. Select a resource.
3. Choose the customer or household.
4. Enter reservation dates and details.
5. Confirm no conflicts exist.
6. Save the reservation.

### Add a maintenance block
1. Open Rentals.
2. Select the resource.
3. Add a maintenance block.
4. Set the blocked range.
5. Save.

## Tips
- Use maintenance blocks instead of notes so conflict detection continues to work.
- Review reservation alerts before high-demand periods.
- Keep resource photos and descriptions current for customer-facing reservation pages.
