# Rentals

## Overview

Rentals manage reservable resources, reservations, maintenance blocks, usage visibility, and rental-related reporting.

## Common Workflows
- create a rentable resource
- book a reservation
- block a resource for maintenance
- check a rental in or out
- review utilization and conflicts

## Step-by-Step: Create a Reservation
1. Open **Rentals**.
2. Select a resource.
3. Create a reservation with date, time, customer, and rules.
4. Confirm there are no conflicts.
5. Review follow-up actions like check-in, check-out, or cancellation.

## Tips
- Maintenance blocks should be used instead of ad hoc notes when a resource is unavailable.
- Reservation conflicts and buffers matter operationally; use the workspace instead of informal tracking.
- Rental activity also feeds reporting and communications.
