# Waivers

## Overview

Cairn supports facility-managed waiver templates, version history, expiration rules, signed record snapshots, customer and guardian signing, and waiver validation in registration and check-in workflows.

## Common Workflows
- create or edit a waiver template
- publish a new waiver version without overwriting signed records
- review missing or expired waivers
- sign a waiver for a customer or household member
- review immutable signed waiver records

## Step-by-Step: Create and Use a Waiver
1. Open **Waivers**.
2. Create or open a waiver template.
3. Review the current version and content.
4. Publish a new version when legal content changes.
5. Review customer waiver status in customer or household profiles.
6. Use portal or public signing routes when self-service signing is needed.

## Tips
- Never edit a signed waiver record in place; Cairn preserves snapshots per signed version.
- Use expiration rules intentionally. Program completion, annual renewal, and fixed-date logic have different operational consequences.
- Waiver status feeds both registration checks and check-in warnings.
