# Product Vision

Cairn is a modern web SaaS platform for climbing gyms, yoga studios, fitness centers, camps, bike parks, and hybrid recreation spaces.

## Vision
- Replace legacy nested workflows with fast, simple operations.
- Make front desk tasks extremely quick.
- Keep the product easy for first-day staff.

## Core principles
- Modern and welcoming UI
- Fast search and check-in
- Minimal clicks
- Flexible data model for mixed facility types
- Tablet-friendly web interface
