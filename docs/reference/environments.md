# Environments

## Local Development
Run Cairn locally with:
```bash
npm install
npm run dev
```

Use your local development server for implementation, testing, and day-to-day changes.

## Hosted Demo
Current demo URL:
- https://cairn-git-main-wylies-work.vercel.app/

Use the hosted demo for product review and stakeholder walkthroughs.

## Documentation Rule
All other docs should stay environment-agnostic and refer to `your Cairn instance` instead of hardcoded hosted URLs.
